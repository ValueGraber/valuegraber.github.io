# ValueGrab: สแกนหุ้น S&P 500 แบบ VI (อัปเดตอัตโนมัติ ฟรี)

เปิดดูเว็บได้ที่ https://valuegraber.github.io

ทุกเช้าวันอังคาร–เสาร์ ราว 05:30 น. เวลาไทย (หลังตลาดสหรัฐปิด) GitHub จะรันสคริปต์ให้เอง
ดึงราคาปิดและตัวเลขพื้นฐานของหุ้น S&P 500 ทุกตัวจาก Yahoo Finance แล้วอัปเดตหน้าเว็บของคุณ
ไม่มีค่าใช้จ่าย และไม่ต้องใช้ Claude

## ติดตั้งครั้งเดียว (ราว 10 นาที)

1. **สมัคร GitHub** ที่ https://github.com/signup (ฟรี) ถ้ามีบัญชีอยู่แล้วข้ามได้
2. **สร้าง repository ใหม่** ที่ https://github.com/new
   - Repository name: `vi-scanner`
   - เลือก **Public** (หน้าเว็บฟรีของ GitHub ใช้ได้กับ repo สาธารณะ ข้อมูลในนี้เป็นข้อมูลตลาดทั่วไป ไม่มีข้อมูลส่วนตัว)
   - ไม่ต้องติ๊ก Add a README แล้วกด **Create repository**
3. **อัปโหลดไฟล์**: ในหน้า repo ที่ว่างอยู่ กดลิงก์ **uploading an existing file**
   แล้วลากไฟล์ `README.md`, `scanner.py`, `requirements.txt` และโฟลเดอร์ `docs` ลงไป → กด **Commit changes**
4. **สร้างไฟล์ตั้งเวลา** (โฟลเดอร์ `.github` มักถูกซ่อนในเครื่อง จึงสร้างบนเว็บง่ายกว่า):
   กด **Add file → Create new file** พิมพ์ชื่อไฟล์ `.github/workflows/update.yml`
   แล้วคัดลอกเนื้อหาจากไฟล์ `.github/workflows/update.yml` ในโฟลเดอร์นี้ไปวาง → **Commit changes**
5. **เปิดหน้าเว็บ**: ไปที่ **Settings → Pages**
   - Source: **Deploy from a branch**
   - Branch: **main** และโฟลเดอร์ **/docs** → กด **Save**
   - รอ 1–2 นาที หน้าเว็บจะอยู่ที่ `https://ชื่อผู้ใช้ของคุณ.github.io/ชื่อrepo/` (ถ้าตั้งชื่อ repo เป็น `ชื่อผู้ใช้.github.io` ลิงก์จะไม่มีหาง)
6. **ทดลองรันครั้งแรก**: ไปที่แท็บ **Actions** → เลือก "อัปเดตข้อมูลหุ้นทุกวัน" → **Run workflow**
   ใช้เวลาราว 15–25 นาที เสร็จแล้วรีเฟรชหน้าเว็บจะเห็นวันที่อัปเดตใหม่ด้านบน

หลังจากนี้ไม่ต้องทำอะไรอีก เปิดลิงก์ดูได้ทุกเวลาทั้งมือถือและคอม (บนมือถือกด "เพิ่มไปยังหน้าจอโฮม" ได้)

## ถ้ามีปัญหา

- **Actions รันไม่ผ่านตอน push**: Settings → Actions → General → Workflow permissions เลือก **Read and write permissions** → Save แล้วกด Run workflow ใหม่
- **Yahoo ปฏิเสธบางตัว**: สคริปต์จะใช้ตัวเลขเดิมของหุ้นตัวนั้นไปก่อน หน้าเว็บไม่พัง
- **หยุดอัปเดตเอง**: GitHub อาจปิดงานตั้งเวลาถ้า repo ไม่มีความเคลื่อนไหวนาน ไปที่แท็บ Actions แล้วกด **Enable workflow**
- **อยากเปลี่ยนเวลา**: แก้บรรทัด `cron` ในไฟล์ `update.yml` (เวลาเป็น UTC = เวลาไทยลบ 7 ชั่วโมง)

## ข้อมูลและวิธีคิด

- แหล่งข้อมูล: Yahoo Finance ผ่านไลบรารี yfinance (ไม่เป็นทางการ), รายชื่อ S&P 500 จาก github.com/datasets/s-and-p-500-companies
- วิธีคำนวณคะแนนดูได้ท้ายหน้าเว็บ หัวข้อ "วิธีคิดคะแนน"
- เป็นเครื่องมือช่วยคัดกรอง ไม่ใช่คำแนะนำการลงทุน
